# PTT Stock Radar

這是一個本機 MVP：貼上 PTT 股票板文章網址，分析「盤後閒聊」中的股票代號、討論熱度、情緒、低估線索與風險旗標，產生可互動儀表板。

## 使用方式

啟動本機儀表板：

```powershell
node .\ptt-stock-radar.mjs serve
```

打開：

```text
http://localhost:8787
```

你可以貼入 PTT Web 版文章網址：

```text
https://www.ptt.cc/bbs/Stock/M.xxxxxxxxxx.A.html
```

也可以按「找最新盤後閒聊」，工具會從股票板最新列表往前找標題含「盤後閒聊」的文章。

## 輸出單一 HTML 報告

```powershell
node .\ptt-stock-radar.mjs analyze "https://www.ptt.cc/bbs/Stock/M.xxxxxxxxxx.A.html" -o report.html
```

## 分數定義

```text
低估候選分數 =
提及數 * 2
+ 不同帳號數 * 3
+ 正向詞 * 2
+ 低估詞 * 5
- 負面詞 * 1.5
- 炒作詞 * 2
```

這個分數是研究雷達，不是投資建議。它適合用來縮小觀察名單，下一步應接上基本面資料，例如本益比、股價淨值比、EPS、月營收、殖利率與法人買賣超。

## 資料過濾

工具會先抓取 TWSE 與 TPEx 公開清單，只有有效台股四碼代號會進入排行。這可以排除「漲 3000 點」、「5000 萬」這類數字誤判。

## 參考性欄位

- 參考等級：綜合不同 ID 數、提及數、低估線索、情緒、炒作詞與 ID 集中度。
- ID 集中度：單一 ID 提及次數占該股票總提及數的比例，越高越要小心洗留言或單一觀點。
- 下一步查核：針對每檔股票列出後續應查的基本面與交易面項目。

## 基本面驗證

目前會接 TWSE/TPEx 公開資料補上：

- 收盤價
- 本益比
- 股價淨值比
- 殖利率
- 估值線索，例如本益比偏低、股價淨值比低於 1、殖利率 >= 5%
- 研究分類，例如「討論熱且估值有支撐」、「討論熱，估值待確認」、「估值便宜但樣本少」
